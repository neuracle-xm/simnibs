# 11　右侧深核得到覆盖时，左侧同名核团是否也成为热点？

全脑和皮层靶外指标可能都合格，却仍存在另一侧同名核团受强场的情况。只对本研究的单侧靶检验这种失败。

## 实验对照

使用同图谱的右、左独立标签 T 和 H。例如 Julich 右 STN=295、左 STN=88；由个体配准分别取掩膜。固定 t=0.10，将基础损失 1−Cov(T,t) 与 1−Cov(T,t)+λ·Cov(H,t) 比较，λ=0.25、1 为开发档。两臂共用方案 05 的靶外预算。

## 两条路线的操作

在 sub1/sub2 上先检查掩膜侧别、体积和左右无交集。两路对同一候选输出左右覆盖、左右 Q50 以及差值；based 在两个掩膜上累计体积，free 将两掩膜绑定到共同脑域。以右海马、右 STN 和右运动皮层做先导；锁定权重后检验完整三皮层对照。

## 结果与判据

报告左右绝对场及其差值。若两侧场都变弱、或热点从左核团迁往其他靶外区，单看左右差变大不能通过。对侧覆盖本来为零时，该罚项的作用有限，保留原目标。

本页比较规则和参数为拟议实验设置。候选库、独立正向复算、三例分工和完整皮层验收均沿用[共同实验协议](02-共同实验协议.md)。实现和数据依据见[Julich 标签表](../../atlas/standardized/JulichBrainAtlas_3.1_207areas_MPM_bilateral_MNI152/labels_zh.csv) · [BN 左右分区](../../atlas/standardized/BN_Atlas_246_1mm/labels_zh.csv)。

## 交给 Codex 的执行单

**输入与启动条件。** 输入为同一独立头模、其配准变换及 03 正向场。运行 `python -m neuracle.demo.ti_depth.exp11 --study-root "$studyRoot" --run-id run-001 --stage pilot` 核对 sub1 的右 295、左 88。开发用 `--stage development` 加入 Brainnetome 海马 216/215、上肢运动皮层 58/57 和 sub2。入口保存左侧配准 mask 与四面体掩膜散列，以及左右世界坐标和 MNI 侧别证据。

1. 核对左右掩膜世界坐标、体积、交集为零。把 `target_label,contra_label` 与散列记录在案。
2. 按候选计算左右 Q50、覆盖及约束可行性。相同外溢预算下比较 λ=0、0.25、1；给首选计算右减左覆盖百分点差。
3. 在 sub2、海马和皮层复核。只对开发有效的权重同步接入 based/free，复算后检查全脑最大热点是否迁到第三处。
