# 方案 13　只在已验证的深部靶启用新目标函数

如果方案 04 或 05 能改善 STN、海马或其他深核，却让现有皮层靶退化，可以把新目标的适用范围限定到预先登记的解剖靶。这个策略回答实际使用中的问题：能否交付一个深部更准、原有皮层仍能命中的结果集？它依赖图谱标签和已验证的个体基线。采用这个策略后，应分别报告深部新算法的收益和复用皮层原解的命中率。

## 在看到保留例之前登记规则

| 输入靶 | 处理规则 | 留下的依据 |
|---|---|---|
| A9/46d_R、A4ul_R、OPC_R、内侧皮层 A24rv_R | 使用本路线现行 ROC；能复用同条件原生基线时，直接复用该具名解及有符号电流。 | 图谱、标签、模型和正向场指纹，以及原基线的绝对定位、覆盖和外溢。A24rv_R 虽在历史目录叫“深部内”，解剖上属于皮层。 |
| 已登记的六个皮层下靶 | 每条路线只采用在 sub1/sub2 开发集上锁定的一种新公式；同次保留该路线的原生 ROC 解。 | 记录新目标、原解和最终选择三行，连同各自的电流与场。 |
| MNI 球、图谱版本未对应或未知标签 | 本轮沿用现行 ROC，注明尚未验证分流。 | 避免把任意坐标只按到头皮距离划成“深部”。这次实验的分流依据是登记图谱及标签。 |

已登记的标签编号和分组依据见[共同协议](02-共同实验协议.md)及[Brainnetome 图谱原文](https://doi.org/10.1093/cercor/bhw157)。查表分流、原解保留和以下选择规则是本项目拟议的工程策略。

## 两条路径的执行与判定

1. **先验证原有皮层是否命中。** 每例每靶按原生设置保存解。如果某个皮层靶的热点本就位于靶外，即使分流前后的电场完全一致，也只记“复现原结果”。同时登记热点到靶区的距离、热点与靶的重叠比例及绝对覆盖。复用已存基线须匹配 T1、网格、帽位、电导率、靶区、目标场强、两路电流约束和求解版本；不匹配时为当前输入重新建基线。[历史审计](01-历史结果审计.md) · [基线手册](03-基线运行手册.md)
2. **深部始终保留原候选。** based 在原生可调电流搜索域中对原 ROC 和新目标分别寻优，记录实际电流。free 在原生固定电流下各自搜索，保留连续解及映射解。比较时两臂各用自己的最终具名电极和实际电流，交给相同正向 FEM。在研究怎样改进目标函数时，另列共同协议的固定电流 ROC0 配对，避免把电流预算变更计作评分收益。[方案 04](04-目标函数-深部定位与皮层热点.md) · [方案 05](05-目标函数-靶区覆盖与外溢约束.md) · [映射及正向核验](22-电极映射与正向复算.md)
3. **固定深部选择规则。** 对每个深部靶，只有新候选相对其原生对照的 `D_hot` 缩短至少 2 mm、新场主阈值覆盖大于零，并逐项满足共同协议的覆盖、靶内强度、皮层热点与全脑外溢限值时，才用新解。其他情况选原解；若原解无效则记该格失败。此规则是一个需要正向复算的新旧二选一流程，须把多一次逆向及复算的费用计入。报告单个新目标的表现与二选一后的表现，可用“等预算再搜一次原 ROC、在两份 ROC 候选间执行同一选择规则”检验收益是否仅来自多一次搜索。
4. **封存后对 sub3 逐靶运行。** 两条路线各出一张十靶表，写明新解命中数、沿用原解数、深部真正改善数、原已命中的皮层保持数和新增失败数。判定沿用共同协议的逐靶和分组门槛。若六个皮层下靶全部被退回原解，则该策略仅复现了基线，深部改善未获验证。若通用新函数已在两路同时通过深部和皮层要求，本方案无需作为首选。

## 交给 Codex 的执行单

**输入与启动条件。** 必须有 03 的原生具名解，以及一项在开发集上锁定的新目标（例如 04 或 05）的配置和可复算物理布局。缺这些实场时先完成所需上游格；不能从文字报告抄判定。 本篇需要专用研究分析。按 02 的入口约定实现或复用后，先调 `python -m neuracle.demo.ti_depth.exp13 --study-root "$studyRoot" --run-id run-001 --stage pilot`，再以同一运行号和 `--stage development` 完成下列开发步骤。两条命令是下一轮实现后的调用方式。

1. 按 02 登记标签映射，为每条路线冻结新目标版本；先在 sub1 的 STN、A4ul 核对一次分流，随后补开发两例十靶。皮层和 A24rv 复用散列一致的原解，验证基线绝对命中及覆盖。
2. 对每个深部目标保存原解、新解及相同条件下的共同正向指标，按正文逐项判断选择或回退。额外用两次原 ROC、同样选择规则及总成本作对照。
3. 冻结选择规则和研究臂后才打开保留例。将结果分成单独新目标、分流结果和双 ROC 三列；失败或找不到原解的格单列。
