# 已有场强三视图绘制方案

从研究结果目录读取具名布局、共同正向场、靶区掩膜和热点指标。覆盖当前开发基线、完整固定候选库、各评分臂和搜索臂的已产出结果，以及已经保存或可由已有载波字段还原的诊断场。正在计算的对照依据已落盘产物登记。对于历史审计、纯数值上界和缺少场的情况，在索引标明证据类型。

在每个头模与靶的个体 RAS 世界坐标里固定三个切面，按脑实质参考四面体取其包络值。采用黑底、统一 0–0.40 V/m 蓝红色标，标记靶区轮廓及主热点正交投影。图例注明色标上限和投影含义。已登记的距离和覆盖指标沿用原始结果表，方向投影、载波缩放等衍生场与共同 FEM 单独标注。

输出至研究结果目录下的三视图汇总。入口可按实验、头模、靶点选择，列出可视化来源及没有场数据的状态。检查索引链接、三视图产物数量、两个头模和不同结果类型的可读性，并以已知 GP、dCa 读数核对位置和覆盖标注。

主入口固定一个头模和一个靶点，首屏显示 03 该靶两路原生基线。04–12 和 20 依据各自的配对表，仅展示该靶在各评分臂的首选和参照。15–16 展示该靶逐靶搜索的已落盘最终场。13–14、17–19 和 21–23 在同靶诊断页展示已登记的场。距离、覆盖及外溢的差值以原实验配对为准，原生基线作为浏览对照。主入口的 CSV 保留同靶结果、来源路径和配对读数。已有全量索引及场图保留以供追溯。

两套浏览页的靶外超阈体积及其配对差值统一显示为 cm³。原始体积按 mm³ 读取，导出的配对差值字段注明 cm³。

主入口的原生基线及 ROC0 参照卡片通过场来源记录读取共同正向仿真的参数文件，分别显示 A、B 两路的电极名、本例有符号电流和对应的参数链接。

ROC0 参照卡片同时说明候选库构成、固定电流下的重算和逐靶选优，并给出两条原生逆向路线共用的阈值 ROC 评分规则。

04 图组上方列出 A、D、P 的定义、三种计分组合和排序方向。D 的强场距离惩罚与结果表中的主热点距靶分别说明。

05 图组上方列出共同覆盖评分的硬覆盖和软覆盖两项，并说明三档选优如何使用同靶 ROC0 的全脑靶外和靶外皮层超阈体积确定上限。

主入口提供 14 电流配比结果的直达链接，按实际出结果的头模和靶点切换。对应靶点的实验列表同时提供独立的 14 选项。

16 结束后，从正式的等预算、从零计时和配对表更新图集及同靶清单，首页提供直达链接。16 图组列出已出场数、完成的计时对照数和未修复跨路供体的放置失败，失败状态链接到原报告。

## 从已有结果生成图集

在 Windows 的仓库根目录激活 `simnibs_env`，使用已落盘的 `neuracle/TI-study-v1` 数据。

```powershell
conda activate simnibs_env
python -X utf8 -m neuracle.demo.ti_depth.render_ti_gallery
```

入口为 `neuracle/TI-study-v1/results/彩色TI场强三视图/index.html`，同目录的 `manifest.csv` 记录同靶结果及配对，`full_audit.html` 和 `full_audit.csv` 用于查看全量场。生成过程读取现有场并复用已生成的场图。
