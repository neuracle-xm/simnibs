# 方案 21　量化深部靶区的空间误差

同一张电场图，换一份偏移几个体素的小核团掩膜，算出的覆盖率就可能改变。这个实验先固定电场，分别检查模板、个体配准和网格取样，量出改变掩膜能造成多大的评价差异。两路均参加。若这项差异与候选目标函数的收益相当，就需要先厘清优化器和评价者是否在同一个地方测量。

## 本地依据

- 仓库中右 STN 对应 Julich 原标签 295，左侧为 88。右侧海马嘴侧部、右上肢运动区在 BN 图谱中分别为 216、58，可作为较大深部靶和皮层对照。运行时读取预生成的独立二值掩膜，前景值为 1。先用原图谱查标签号，再用二值图取前景。[Julich 标签表](../../atlas/atlas/JulichBrainAtlas_3.1_207areas_MPM_bilateral_MNI152/JulichBrainAtlas_3.1_207areas_MPM_bilateral_labels_zh.csv) · [BN 标签表](../../atlas/atlas/BN_Atlas_246_1mm/BN_Atlas_246_labels_zh.csv) · [提取掩膜](../../atlas/generate_standardized_rois.py)
- 图谱注册表给 Julich 指定 09c 非线性非对称参考模板，标准化脚本给离散标签调用 `resample_from_to(..., order=0)`，目标网格取自 SimNIBS 的 `MNI152_T1_1mm.nii.gz`。这一步按两个 NIfTI 的仿射和形状重采样。模板间是否还存在局部解剖差异，需对照 T1 源图核验。同名 MNI、形状一致、仿射一致只能确认部分空间信息。[图谱及模板注册表](../../atlas/registry.py) · [标准化流程](../../atlas/standardize_atlases.py) · [现有验证脚本](../../atlas/validate_standardized_atlases.py)
- 两路入口共用 `build_optimization_rois`。Atlas 通过个体非线性变换、最近邻取样及 WM/GM 限制得到靶区。MNI 坐标输入则先将中心变换到个体，再在个体空间生成球。MNI 球模式的 non-ROI 默认去除同中心 25 mm 球，故半径小于 25 mm 时，小球外到 25 mm 之间的脑组织没有进入原 focality 的任一分母。评价场图时把这圈单独列出，再计入全脑靶外汇总。基线复刻时保留原设置。[共享 ROI 构造](../../utils/optimization_roi.py) · [SimNIBS 掩膜和球的实现](../../../simnibs/utils/region_of_interest.py)
- Based 在 HDF5 内嵌的 WM/GM 四面体上取单元中心及体积。Free 从完整头模网格定义体积 ROI。导出的 T1 体素场经过线性插值，量化主分析使用原网格。[Based 元素对齐](../../ti_leadfield_optimization/regions.py) · [Free 区域设置](../../ti_optimization/electrodes_roi.py) · [导出实现](../../utils/ti_export.py)

## 实验单与步骤

1. 准备 sub1–sub3 三个完整 m2m，归档来源、个体 T1、网格、`toMNI` 变换和参考模板的哈希。现有归档缺原始变换且部分派生结果重复。依共同协议先核对三个扫描输入，再从各自原 T1 重建。若找到原始 m2m，单列历史复查。选右 STN、rHipp_R、A4ul_R，共 9 个个体靶区。每个靶区冻结两路原目标各一张最终场图，共 18 张。先在 sub1/sub2 整理 12 张，锁定规则后在 sub3 前瞻性检查余下 6 张。主评价阈值 0.10 V/m，0.20 V/m 作敏感性检查。归档图中的手工光标位置不能代替掩膜。[共同实验协议](02-共同实验协议.md)
2. **对照解剖模板。** 将带标签的原始图谱叠加到其随附 T1，以相同的世界坐标检查原图与标准化图在右脑、脑室和深部中线标志处的关系。登记原模板名称、文件摘要、轴向、仿射、单位、中心和体积。先比较模板 T1 的对应解剖。若模板来源或局部对应未核实，把该例标为“模板对应待核验”。有可靠模板间变换时，新增“模板间变换 + 个体变换”对照，由完整变换一次性按最近邻取标签，同时保留现有链的结果。
3. **导出个体掩膜。** 优先沿用求解器实际的 `mni_mask_to_sub` 参考图选择，存在 `subject_files.T1_upsampled` 时用它，否则用 `subject_files.reference_volume`；另在原生 T1 网格导出一份供目视复核。以下命令用于后者。在仓库根目录、conda 环境已配置的 PowerShell 里运行，替换数据根并先建独立的空输出目录。

   ```powershell
   conda activate simnibs_env
   $studyRoot = Join-Path (git rev-parse --show-toplevel) 'neuracle/TI-study-v1'
   $subjectDir = Join-Path $studyRoot 'head_models/m2m_sub1'
   $qcDir = Join-Path $studyRoot 'results/21/run-001/masks/sub1'
   New-Item -ItemType Directory -Force -Path $qcDir | Out-Null
   $atlasMask = 'neuracle/atlas/standardized/JulichBrainAtlas_3.1_207areas_MPM_bilateral_MNI152/rois/0295_STN_Subthalamus_rh.nii.gz'
   python -m simnibs.cli.mni2subject -i $atlasMask -m $subjectDir -o "$qcDir/STN_R_T1.nii.gz" -r "$subjectDir/T1.nii.gz" -t nonl --interpolation_order 0
   ```

   对 BN 区域分别换成 `BN_Atlas_246_1mm/rois/0216_rHipp_R.nii.gz`、`BN_Atlas_246_1mm/rois/0058_A4ul_R.nii.gz`，改输出名。三正交面逐层检查侧别、连通性、靶区与组织边界，并记录复核人和是否能从该 T1 辨认边界。仅见 T1 且不能辨认 STN 边界时，只评价“相对指定图谱靶的准确度”。[本地 CLI 定义](../../../simnibs/cli/mni2subject.py) · [SimNIBS 坐标约定](https://simnibs.github.io/simnibs/build/html/documentation/coordinates.html) · [Ewert 等，2019，小核团配准与专家分割比较](https://www.sciencedirect.com/science/article/pii/S1053811918318664)
4. **量化取样差异。** 对 native 二值掩膜记录体素数和体积（体素数乘仿射线性部分行列式的绝对值）。再取其与统一 WM+GM 的交集作为可评价区域。分别提取 free 网格和 based 内嵌网格靶内四面体的个数、单元体积中位数、体积和、体积加权质心及与个体交集掩膜的质心差（mm）。比较两网格时，先在同一个个体物理网格按所属四面体回填标签，再算 Dice 和质心差。只用相同组织交集比较；同时登记裁切掉的靶体积，尤其留意局部是否在 CSF 窗口丢失。空靶、错侧、缺变换或无有效覆盖单独报错。
5. **隔离掩膜敏感度。** 保持 18 张场图及电极固定。将个体掩膜沿世界坐标左右、前后、上下分别平移 ±1 mm 和 ±2 mm（12 个情形，加原位共 13），使用最近邻重新取样并与当前组织域求交。这是人为设定的压力测试幅度。每次重算共同协议的定位、靶区覆盖、靶内平均场和皮层靶外热点。另记固定热点群至移动后 ROI 的最近距离。配准误差造成的变化形态可能比这组刚性平移更复杂。
6. **条件复算。** 只有找到可追溯的模板变换错误、错标或网格取样问题，才在修订的 ROI 上以两路原目标各重跑，并把旧、新电场都交叉评价于旧、新掩膜，形成 2×2 表。先冻结评价掩膜及其解剖依据，随后比较场；另列“同场换掩膜”的差值。没有独立边界证据时，结论仅限两条 ROI 链之间的敏感度。

## 判读

每个“头模 × 靶点 × 方法”一行，记录原位值、偏移情形范围、原位深部改善相对同场偏移变化的大小。若新目标函数带来的定位或覆盖改善落在测得的偏移范围内，就标记“对 ROI 不确定性敏感”，保留每个方向的数值；若改进方向在 13 种情形均一致且仍通过共同协议的深部及皮层门槛，记录为“通过本次位移检验”。当模板链核对无异常、两网格差异在各自离散分辨率内且原位/偏移结论一致，本实验对“坐标链解释主要失败”提供的支持有限。尺寸、Dice 或往返一致性只衡量几何一致程度，无法确认该个体的真实核团位置。[Nowacki 等，2018，个体 MRI、图谱与 STN 定位对照](https://pmc.ncbi.nlm.nih.gov/articles/PMC6169097/)

## 交给 Codex 的执行单

**输入与启动条件。** 使用 03 中同个体的 T1、两向变换、原 atlas、体积标签和两路最终场；用 02 的 `targets.csv` 定位三个 ROI。这里的实验数据是固定场和移动的掩膜。 本篇需要专用研究分析。按 02 的入口约定实现或复用后，先调 `python -m neuracle.demo.ti_depth.exp21 --study-root "$studyRoot" --run-id run-001 --stage pilot`，再以同一运行号和 `--stage development` 完成下列开发步骤。两条命令是下一轮实现后的调用方式。

1. 先做 sub1/STN，按前文现有 `mni2subject` 入口生成 T1 网格掩膜，在轴、冠、矢状面标出个体解剖与原目标。再在两路实际求解网格采样，比较体积、质心、组织交集和左右。将图谱号、源模板、变换路径和散列写进 `mask_chain.csv`。
2. 在两开发头模的三个 ROI、两条路线的固定原生场上，依次套用原位与 ±1/±2 mm 六向平移。每格 13 个状态，开发共 12 份固定场、156 条位置读数；另存旧新掩膜的 Dice、偏移向量和靶区体积。
3. 只在查得可追溯的错标、变换或取样问题时才补算旧/新 ROI × 旧/新场的四格交叉表；结果首页明确使用了哪份解剖证据。两者都合理时报告敏感性范围。
