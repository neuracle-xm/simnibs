# 用现有入口跑第一对基线

以下是将来执行实验的 PowerShell 7 命令。先跑 sub1 的右 STN，再换成右海马（BN 216）和右运动皮层（BN 58）。同一终端依次执行各段。头模和各次仿真写入独立研究目录。命令与 `c72cc527` 版入口核对过，三项 `--help` 和当前 conda 环境中的 based 依赖已检查。建模、逆向寻优和正向计算尚待实验时执行。

## 用原始 T1 建模

在仓库根目录运行。示例使用项目内的实验目录 `neuracle/TI-study-v1`。三套头模可以先建模，sub3 新方案的结果按协议封存至参数锁定。

```powershell
Set-Location 'C:\Users\50609\Documents\simnibs'
conda activate simnibs_env
if ($env:CONDA_DEFAULT_ENV -ne 'simnibs_env') { throw '请先激活 simnibs_env' }
$ErrorActionPreference = 'Stop'
$studyRoot = Join-Path (git rev-parse --show-toplevel) 'neuracle/TI-study-v1'
$rawRoot = 'C:\Users\50609\Downloads\TI逆向仿真结果\头模数据'
foreach ($sid in 'sub1','sub2','sub3') {
    $scans = @(Get-ChildItem -LiteralPath (Join-Path $rawRoot $sid) -Filter '1_sT1W*.nii.gz' -File)
    if ($scans.Count -ne 1) { throw "$sid 原始 T1 数量不符" }
    $m2m = Join-Path $studyRoot "head_models/m2m_$sid"
    if (Test-Path -LiteralPath $m2m) { throw "$m2m 已存在，请核实此次实验的目录与输入" }
    New-Item -ItemType Directory -Path $m2m -Force | Out-Null
    Copy-Item -LiteralPath $scans[0].FullName -Destination (Join-Path $m2m 'T1.nii.gz')
    Get-FileHash -LiteralPath $scans[0].FullName | Format-List Path,Hash
    python -m neuracle.head_model $studyRoot $sid
    if ($LASTEXITCODE -ne 0) { throw "$sid 建模失败，检查该头模 logs" }
    foreach ($file in "$sid.msh",'eeg_positions/EEG10-10_NSN.csv','toMNI/MNI2Conform_nonl.nii.gz','toMNI/Conform2MNI_nonl.nii.gz') {
        if (!(Test-Path -LiteralPath (Join-Path $m2m $file))) { throw "$m2m 缺少 $file" }
    }
}
```

如任务中断，在核实输入散列和已有进度后，单独重调 `python -m neuracle.head_model $studyRoot $sid`。原 MRI 保留在下载目录。检查个体 T1、分割、目标侧别和帽位以后再计算逆向。每个头模使用自己的 `eeg_positions` 与 `toMNI`。[建模入口](../../head_model.py) · [网格与帽位生成](../../charm/mesh.py) · [变换文件命名](../../../simnibs/utils/file_finder.py)

## 各跑一次原生 ROC

**已有结果时从哪里接续。** 上一段是新目录首次建模示例。再次执行本篇时，先读 `results/03/<run-id>/cases.csv` 与 `artifacts.csv`，逐例核对 01 的源 T1 散列、已建网格散列、变换和帽位文件。匹配且齐全就直接使用已有 m2m；部分完成按上节单例命令恢复。对于已成功的逆向任务，若缺共同正向，只运行下文的正向段并选该路线。对于已成功的正向任务，若仅缺结果表，直接从两份载波网格补做指标提取。改变输入或布局时新建任务 ID 并保留旧结果。不要为补一张 CSV 而重跑三个头模。

foreach ($atlas in 'JulichBrainAtlas_3.1_207areas_MPM_bilateral_MNI152','BN_Atlas_246_1mm') {

首例沿用截图的 NSN 帽和 0.10 V/m 靶阈值。free 原生基线采用旧测试默认的两路各 2 mA 离线输入，based 原生基线沿用正式入口的自动寻流。目标函数对照 ROC0 和新方案在两条路线均另以固定两路各 1 mA 寻优。新实验的原始输入与电流约束都应随结果归档。设置中的十种电导率来自仓库标准表。[参数常量](../../utils/constants.py) · [两路分发及输入目录](../../ti_inverse.py) · [参数校验](../../parameters/validator.py)

```powershell
$sid = 'sub1'
$targetKey = 'stn295'
$atlasName = 'JulichBrainAtlas_3.1_207areas_MPM_bilateral_MNI152'
$label = '295'
$targetThreshold = 0.10
$thresholdTag = 't{0:000}' -f [int][Math]::Round(100 * $targetThreshold)
$fixedInputs = @{
    montage = 'EEG10-10_NSN'
    roi_type = 'atlas'
    roi_param = @{atlas_param = @{name = $atlasName; area = $label}}
    target_threshold = $targetThreshold
    anisotropy_type = 'scalar'
    electrode_radius = 6
    conductivity_config = @{
        WM = 0.126; GM = 0.275; CSF = 1.654; Bone = 0.01; Scalp = 0.465
        Eyes = 0.5; CompactBone = 0.008; SpongyBone = 0.025; Blood = 0.6; Muscle = 0.16
    }
}
foreach ($route in 'leadfield_free','leadfield_based') {
    $task = "$($sid)_$($targetKey)_$($route)_native_$thresholdTag"
    $outDir = Join-Path $studyRoot "simulations/ti_inverse_$task"
    if (Test-Path -LiteralPath $outDir) { throw "已有同名任务 $task" }
    New-Item -ItemType Directory -Path $outDir -Force | Out-Null
    $inputs = $fixedInputs.Clone()
    $inputs.optimization_method = $route
    if ($route -eq 'leadfield_free') {
        $inputs.current_A = @(2.0,-2.0)
        $inputs.current_B = @(2.0,-2.0)
    }
    $inputs | ConvertTo-Json -Depth 8 | Set-Content -LiteralPath (Join-Path $outDir 'params.json') -Encoding utf8NoBOM
    python -m neuracle.ti_inverse $studyRoot $task $sid
    if ($LASTEXITCODE -ne 0) { throw "$task 失败，检查 $outDir/logs" }
    Get-Content -LiteralPath (Join-Path $outDir 'electrode_mapping.json') -Raw
}
```

其他靶点只替换本段开头的 `$targetKey`、`$atlasName`、`$label`，索引见共同协议。开展 0.20 V/m 再寻优时，将 `$targetThreshold` 改为 0.20 并重新执行本段及下段，逆向和正向任务都会带有 `t020`。based 的 `current_A/current_B` 连 `null` 都不能传，GA 的种子、步长等也不从业务 JSON 接收。为缺失、零场、空 ROI 等情况保留任务行。free 归档连续位置、映射位置与最终网格。based 归档 `optimization_result.json`、`leadfield_reference.json`、`convergence.csv`、结果网格和缓存标识。两路应都有 `electrode_mapping.json`。[based 输出](../../ti_leadfield_optimization/run.py) · [共同实验协议](02-共同实验协议.md)

## 用相同正向入口重算获选布局

在上节原生任务完成后运行。`mapped_labels` 顺序为 A+、A−、B+、B−，电流直接取各自结果。得到的逐路复算结果用于检查场的一致性。固定电流候选池另写新任务 ID，两个通道都用协议预设电流重新求场。[具名布局结果结构](../../utils/optimization_result.py) · [TI 正向入口](../../ti_forward.py)

```powershell
foreach ($route in 'leadfield_free','leadfield_based') {
    $task = "$($sid)_$($targetKey)_$($route)_native_$thresholdTag"
    $invDir = Join-Path $studyRoot "simulations/ti_inverse_$task"
    $cfg = Get-Content -LiteralPath (Join-Path $invDir 'params.json') -Raw | ConvertFrom-Json
    $sol = Get-Content -LiteralPath (Join-Path $invDir 'electrode_mapping.json') -Raw | ConvertFrom-Json
    if ($sol.current_A[0] -eq 0 -or $sol.current_B[0] -eq 0) {
        Write-Warning "$task 的一个载波为零；记录包络为零及定位失败"
        continue
    }
    $fwd = @{
        montage = $cfg.montage
        anisotropy_type = $cfg.anisotropy_type
        conductivity_config = $cfg.conductivity_config
        electrode_radius = $cfg.electrode_radius
        electrode_A = @(
            @{name=$sol.mapped_labels[0]; current_mA=$sol.current_A[0]}
            @{name=$sol.mapped_labels[1]; current_mA=$sol.current_A[1]}
        )
        electrode_B = @(
            @{name=$sol.mapped_labels[2]; current_mA=$sol.current_B[0]}
            @{name=$sol.mapped_labels[3]; current_mA=$sol.current_B[1]}
        )
    }
    $outDir = Join-Path $studyRoot "simulations/ti_forward_$task"
    if (Test-Path -LiteralPath $outDir) { throw "已有正向任务 $task" }
    New-Item -ItemType Directory -Path $outDir -Force | Out-Null
    $fwd | ConvertTo-Json -Depth 8 | Set-Content -LiteralPath (Join-Path $outDir 'params.json') -Encoding utf8NoBOM
    python -m neuracle.ti_forward $studyRoot $task $sid
    if ($LASTEXITCODE -ne 0) { throw "$task 正向复算失败" }
    Get-ChildItem -LiteralPath $outDir -Filter '*_TI.msh'
}
```

首轮完成的标志是每种方法都有一份可追溯的 ROI、具名解、正向场和指标行，或有可核查的失败原因。热点、覆盖、外溢的定义和通过条件见[共同实验协议](02-共同实验协议.md)。复算的电极层模型、向量对齐和误差比较见[方案 22](22-电极映射与正向复算.md)。后续目标函数需要离线评分或实验适配层，方案 04、05 给出了各自的公式与接入位置。

完成 02 的登记并建好独立头模后，可使用研究入口顺序调用原有的正逆向 CLI。各 `m2m_*` 目录的 `study_source_sha256.txt` 应在复制原始 T1 时写入 01 登记的源文件完整散列。运行前检查头模完成进度、网格和散列。已成功的同配置原生任务以参数及产物散列复用。

```powershell
conda activate simnibs_env
python -m neuracle.demo.ti_depth.exp03 --study-root neuracle/TI-study-v1 --run-id run-001 --stage pilot
```

`--jobs 3` 可同时运行同一头模的三个独立场任务。每格仍先算逆向，再用该格具名解正向复算。候选库在该头模原生格完成后生成，其中各布局也可并行复算。主进程按完成顺序对齐、验收并更新结果表，每格保存独立命令脚本。并发数默认 1，可结合机器可用内存与求解器线程数调整。相同原生任务按配置与散列复用。

Windows 上报告文件被短时占用时，原子替换会在限定时间内重试。持续拒绝访问会保留原状态表和已写出的求解产物，释放占用后可用同一运行编号接续。

先导完成后使用 `--stage development` 补齐开发矩阵。候选扰动按个体帽位间距离查找每个电极的最近合法替换，四个帽位互异，中心至少相距 17 mm（两片半径各 6 mm，加 5 mm 间隔）。原生具名布局作为候选种子，筛查场统一用共同正向模型和两路各 1 mA。候选索引保存直接复算得到的场与精确对齐、同组织重心取样的证据。

## 交给 Codex 的执行单

**输入与启动条件。** 用 01 登记的三份原始 T1、02 的 `targets.csv`/`matrix.csv` 和 `simnibs_env`，先检查 `head_models` 中可复用的已验证产品。 使用本篇列出的本地文件或现有命令，并按下列步骤生成交接材料。

1. 依次运行本篇建模、逆向、正向三段命令；图谱已具备则跳过恢复段。首格用 sub1/stn295。随后替换成 rhipp216、a4ul58 的 atlas/标签和任务名，原生两路各三格。保存实际调用和退出码。
2. 逐个任务把 `electrode_mapping.json`、`params.json`、原生场、两个正向载波网格、TI 网格和日志登记在 `artifacts.csv`。运行 02 的提取器，与共同 ROI 对齐，生成六格的距离、覆盖、强度和外溢；回填 02 的真实场校验。
3. 将成功的具名布局从两路合并；先导时用本头模已有布局，每个电极尝试一个合法最近邻替换并去重，在两路各 1 mA 下重算共同场，生成 `shared/<subject>/<data_id>/candidates.csv` 和逐场数组。开发阶段按 02 扩至两例十靶、40 个原生格，冻结新版库并记录 data_id，后续所有参比与实验臂使用同一版。
